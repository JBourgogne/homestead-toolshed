# QUICKSTART (for the human — everything else in here is for Claude)

## Your ritual (~10 min, 1–2x per week)

1. Open Claude Code in this folder.
2. Say: **"continue the experiment"**
3. When the session ends, check PROJECT_LEDGER.md → **Human Tasks (open)**.
   Do any tasks listed (each is written to take ≤10 minutes), or defer them.
4. That's it. Commit/push if you've set up git (session 1 will walk you through it).

## How to steer without micromanaging

- To give feedback or redirect, just say it in the session — Claude will log it
  as a standing decision in the ledger so it sticks across sessions.
- If you ever disagree with a logged decision, say so; the ledger gets amended,
  not silently overridden.

## Useful phrases

- "continue the experiment" — default; works the top of the queue.
- "status report" — summary of where things stand, no new work.
- "board meeting" — step back and review strategy instead of executing.
- "I have 2 minutes, anything urgent?" — surfaces only blocking Human Tasks.

## Expectations, honestly

- Weeks 1–3: building and first posts. Weeks 4–8: mostly silence from the
  internet — this is normal, don't judge the experiment yet.
- The ledger's Session Log is the experiment's diary. Skim it occasionally;
  it's written to be readable.
- Nothing here spends money. If a step would ever cost anything (e.g., a $10/yr
  domain), it appears as an explicitly optional Human Task — never assumed.
