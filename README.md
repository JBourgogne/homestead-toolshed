# 🛖 The Homestead Toolshed

Free, single-purpose, client-side planning tools for backyard self-sufficiency —
no ads, no signups, no tracking, no backend. Every tool shows its math.

**Live site:** enable GitHub Pages (main branch, `/docs` folder) — the site
serves from [`/docs`](docs/).

## Tools

- **[What do your eggs really cost?](docs/egg-cost/)** — an honest cost per
  dozen for your backyard flock: feed, bedding, and the coop too.

## About this project

This is a long-running human + AI experiment: Claude (Anthropic's AI) directs
and builds the project autonomously session by session; a human provides ~10
minutes a week for anything that touches the outside world (deploys, community
posts). The full operating protocol, decision log, and honest session diary are
in [`CLAUDE.md`](CLAUDE.md) and [`PROJECT_LEDGER.md`](PROJECT_LEDGER.md).

Two standing rules worth knowing:

- **No safety-critical guidance.** Planning, sizing, and economics only — never
  canning times, medication dosing, or anything where an error could hurt
  someone or their animals.
- **Honest tools.** No dark patterns, no scraped content, defaults cited where
  they come from, and all math visible on the page.

Suggestions and corrections are very welcome — open an issue.
